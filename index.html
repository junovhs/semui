What you're seeing: SEMUI is a Rust library that ingests HTML + CSS and converts it into a clean, normalized Intermediate Representation (IR) — capturing layout, paint, and typography explicitly for every node. The IR is then emitted back as HTML + CSS. Before is the hand-authored source; After is what the emitter produces from the IR alone, with zero structural drift between the two passes. Right now SEMUI proves the invariant: round-trip fidelity in HTML. But HTML → HTML is just the proof of concept — the IR itself is the point. Once we can extract a reliable, renderer-agnostic description of what a UI actually is — resolved coordinates, explicit typography, semantic node kinds — we can compile it to anything: SwiftUI, WGPU, Egui, Dioxus, Jetpack Compose. You design in HTML because AI understands it best. SEMUI is the layer where that design becomes law. Emitters execute the law on any runtime.
